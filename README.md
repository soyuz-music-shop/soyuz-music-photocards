# SOYUZ MUSIC — Ozon PhotoCards

Отдельный репозиторий для подготовки и проверки инфокарт и изображений упаковки SOYUZ MUSIC. Сайт находится в другом репозитории — [soyuz-music-store](https://github.com/soyuz-music-shop/soyuz-music-store) — и не изменяется этим проектом.

## Настройки Ozon из проекта сайта

В исходном сайте используются:
- Seller API: `https://api-seller.ozon.ru`;
- заголовки `Client-Id` и `Api-Key`;
- секреты GitHub Actions `OZON_CLIENT_ID` и `OZON_API_KEY`.

Источники: `OZON-API-SETUP.md`, `.github/workflows/sync-ozon.yml`, `scripts/sync_ozon.py` действующего сайта. Значения ключей не раскрыты и не перенесены.

## Что делает этот проект сейчас

- `scripts/check_ozon.py` — проверяет доступ к Ozon методом чтения списка товаров;
- `.github/workflows/check-ozon.yml` — только ручной запуск проверки;
- `photocards/` — резервная папка для ограниченного теста;
- `OZON-API-SETUP.md` — инструкция по настройке секретов только в новом репозитории.

**Ни отправки на модерацию, ни изменения галерей Ozon, ни массовой загрузки пока нет.** Перед изменением фотографий должны быть подтверждены исходные URL, порядок изображений и реальная доступность новых HTTPS-ссылок.

## Безопасность

- Репозиторий сайта `soyuz-music-store` не изменяется.
- Данные API-ключей и токенов не публикуются.
- Секреты Actions требуется настроить отдельно в новом репозитории.
- GitHub Pages не предназначен для постоянного коммерческого хостинга изображений.

Сведения о методах Seller API взяты из проекта сайта и могут нуждаться в проверке перед запуском.
